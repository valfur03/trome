# The E2E test classes that a merge runs for a changed file of app code, on top of the core checks (core_e2e_classes in
# code-paths.sh, and make release-run-check), which run at every merge of app code.
# One line: a pattern of paths (a shell pattern, in which * also matches /), then the classes, or - for the core checks only.
# A changed file of app code that no line matches runs the full suite: a doubt never skips a test.
# A file that several lines match runs the classes of each of them.
# A line gives the classes whose test reads that code; the daily full run (make full-run) catches what a line misses.
# The classes are the file names of ios/UITests/.
